# Segurança

## Relatar uma vulnerabilidade

Não publique detalhes de uma possível vulnerabilidade em uma issue aberta.
Use a opção **Report a vulnerability** na área **Security** do repositório no
GitHub para enviar o relato de forma privada.

Inclua, quando possível:

- versão ou commit afetado;
- passos mínimos para reproduzir;
- impacto observado;
- sugestão de correção, caso tenha uma.

Não inclua arquivos pessoais, planilhas reais, credenciais ou dados sensíveis no
relato. O projeto ainda não possui prazo formal de resposta, mas os relatos serão
avaliados conforme a disponibilidade do mantenedor.
